Create: TweedleDee n' Tweedle Dumb is a Minecraft mod that adds two plushies, Tweedle Dee and Tweedle Dumb.

The plushies can be placed in the world, sit on your shoulders, and be equipped through Curios. Each plushie can store fluids and provide configurable status effects.

The mod also adds a mechanical crafting progression using Create, and plushies can occasionally be found sitting in villages.

Curios is optional.
